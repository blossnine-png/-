# 万法宗 · 万法机关令 1.0.0

酒馆助手前端控制脚本。配合《道渊》及匹配的万法宗扩展世界书，复用原卡唯一MVU，不安装第二个MVU。

托管运行模块 `wanfa.js` 与仙城图片 `wanfa-city.png` 分开保存。运行模块不自行启动，只有导入加载器完成校验后才启动；不收集或上传聊天、变量、设置或API密钥。正常使用时的模型更新仍遵从玩家原有设置。

支持原木/玄青切换、六栏目、分组详情、原有任务与资源规则、出宗按需上下文、焦点/选区/滚动保留，以及操作附近反馈。

安装时只启用一份万法宗脚本。托管版与完整本地版使用同一脚本ID，以替换升级。加载器固定到已发布的Git提交，并校验运行模块SHA-256；导入后需要能够访问GitHub或CDN。

此目录仅包含发布所需的程序与图片。未包含真实聊天或测试会话备份。
