# 万法机关令 1.1.0

适配117条万法宗拓展.json及《道渊》v5.5.4。默认玄青与月亮，可切回原木并记忆选择。集成木刻回纹、云纹与阵盘，宗籍页显示已确认的进行中经历；功德堂可查看任务目标、报酬、时限和验收，再拟写接取申请。仙城各设施使用独立入口。

全部业务资料读取当前聊天的MVU，程序不含示例名籍或真实聊天。刷新任务只拟写请求，不本地捏造任务、不覆盖已有委托。未确认不计时，奖励按冻结凭据一次结算。

运行模块和图片分别托管；入口固定运行提交，校验代码SHA-256，支持CDN与GitHub备用源。安装时只启用一个万法宗脚本，沿用脚本ID以替换升级；世界书仍须另行导入。

根目录“万法宗独立脚本.js”为本次入口，单行import应固定到本次入口提交。网络不可用时使用本地完整版。
